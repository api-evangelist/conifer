# Conifer

> Conifer (YC S26) builds Sage, a local-first AI runtime and workspace that runs models entirely on your own machine. A from-scratch Rust inference engine (up to 60% faster decode than llama.cpp on Apple Silicon) pairs an editor, integrated terminal, file viewers, and an agent runtime inside a kernel-level sandbox. Conifer routes each request to the cheapest capable model — starting with free on-device inference — cutting AI spend by up to 80%. It ships as the Juniper desktop app for macOS, Windows, and Linux with no accounts, no telemetry, and no cloud dependency. Conifer is proprietary and exposes no public web API.
